# E-Commerce Sales Analysis - Power BI

## Project Overview

This project analyzes e-commerce sales data using Microsoft Power BI. The project focuses on data preparation, data modeling, DAX calculations, and visualization to analyze sales performance across different categories, sub-categories, locations, and time periods.

## Dataset

The analysis was developed using e-commerce data containing information related to orders, sales, profit, quantity, product categories, locations, and sales targets.

## Data Analysis and Visualization

### 1. Sales Performance
- Analyzed total sales and sales targets across product categories.
- Created KPI cards to display key sales figures.

### 2. Sales Trend Analysis
- Analyzed sales performance over time using a monthly sales trend visualization.

### 3. Profit and Product Analysis
- Analyzed profit and quantity across different product sub-categories.
- Compared performance across product categories and sub-categories.

### 4. Geographic Analysis
- Analyzed sales and order performance across different locations.

### 5. Data Modeling and DAX
- Created relationships between relevant tables for analysis.
- Used DAX calculations to create calculated columns and measures.
- Created a Calendar table to support time-based analysis.

## Visualizations

The Power BI report includes:
- KPI Cards
- Column and Bar Charts
- Line Chart
- Matrix
- Map
- Treemap
- Scatter Chart
- Donut Chart
- Funnel Chart
